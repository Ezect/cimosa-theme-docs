# Cimosa support

Need help with the Cimosa theme? We are happy to help.

## Contact

Support: https://github.com/Ezect/cimosa-theme-docs/issues (open an issue)

We reply within 2 business days (Monday to Friday, Central European Time).

## What to include

1. Your store URL (the myshopify.com address is fine).
2. The page where the problem happens, with the link.
3. What you did, what you expected and what happened instead.
4. Your browser and device (for example Safari on iPhone).
5. A screenshot or a short screen recording.
6. If you are not sure the theme is the cause, tell us which apps are installed.

Never send us your password. If we need to look at your store we will ask you for a collaborator request, which you can remove at any time.

## What support covers

- Installing and setting up the theme.
- Using the theme settings, sections and blocks.
- Bugs and problems in the theme code.
- Free updates for bug fixes and compatibility with Shopify changes.

## What is not covered

- Custom design or code changes made for your store.
- Problems caused by third-party apps or by code you added yourself.
- Writing your content, photos or product data.

For custom work, hire a Shopify Partner. Before following any guide that edits code, duplicate your theme first.

## Before you write

- Read the documentation (DOCUMENTATION-EN.md), especially the Troubleshooting section.
- Check that Theme settings > Motion effects is set the way you want.
- Try the page in a private window with apps disabled, if you can.
